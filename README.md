# SCOUR-COMPLETE
Development framework for SCDOT-oriented culvert outlet scour and protection. NOT independently verified for design. The Mew ten-block regression engine is in legacy/. Intentional R01 corrections are listed in docs/QC_RESPONSE_R01.md. Start with HANDOFF.md and docs/ARCHITECTURE.md.
Run: python gui.py (JSON object or array); python scour_complete.py inputs.json --out results.json. Install optional planned graphics/report dependencies with pip install -r requirements.txt. Run tests with python -m pytest or pytest -q.
Current scaffold wraps legacy calculations, isolates batch errors, exports JSON and displays inference warnings. It deliberately returns no recommended alternatives until independent verification. GUI import accepts a paired HY-8 project and result file. Export PDF, text and velocity graphics from the GUI. The reporting API also supports an optional orbit view. Independent jet decay and natural-bed scour remain pending.
SCDOT RHDS (May 2009), §2.2.11, requires investigation of every culvert outlet for scour using HEC-14. M4 selection must consider outlet flow regime and bed/bank soil erodibility. Figure 10.4 is an apron schematic. Construction-phase stormwater controls require separate evaluation. Other jurisdictional methods must be labeled not SCDOT confirmed.
Inferences: I01 ranking is engineering judgment; I02 conceptual 3D surfaces are illustrative; I03 inherited construction details are project-specific; I04 interpolation of HY-8 velocities is not independent jet prediction. See docs/VERIFICATION.md. Public repository: never commit confidential project inputs.

The desktop GUI requires Tk (test with python -m tkinter). Graphics, PDF and tests use requirements.txt. Dependency versions are lower bounds; record resolved versions when reproducing a review.
