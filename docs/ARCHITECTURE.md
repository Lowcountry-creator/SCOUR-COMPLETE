# Architecture and milestone plan
M1 baseline: preserve legacy engine and parser, regression tests and synthetic examples.
M2 engineering verification: obtain official HEC-14 third edition, HEC-15 third edition, HEC-22 fourth edition, HDS-5 and applicable SCDOT specifications. Record exact page/equation, units, applicability, independent example and test result for each method. Resolve prior QC: basin Fr gate, Q/A mismatch, full barrel depth, multiple jets, bank stability, fixed construction details, jet vs ambient velocity. Verify SCDOT classes; do not silently assume.
M3 methods: separate pure functions for natural-bed scour (HEC-14 ch5), jump (ch6), basin/apron/downstream (ch10), HEC-15 lining. Use published jet velocity decay procedure in HEC-14, including required geometry and coefficients; check against HY-8 manually transcribed 1–4 LB velocities across low/high tailwater and outlet shapes. Do not fit an arbitrary decay curve or treat interpolation as independent prediction. If inputs missing or method outside domain, withhold result. Retain manual HY-8 velocities as independent comparison. Record provenance and discrepancy.
M4 decision engine: candidate status verified/conditional/ineligible; only independently benchmarked, applicable, hydraulically adequate candidates can rank. User-authorized FHWA/SCDOT first; supplemental methods labeled not SCDOT confirmed. Ranking policy is engineering inference, not agency rule. Require footprint, channel stability, construction constraints; cost only when supplied. Return zero to two distinct alternatives, reasons and exclusions.
M5 batch: manifest JSON per crossing/culvert/event, source paths and units, manual overrides with provenance; isolate errors, no silent defaults; aggregate governing event by metric, CSV/JSON and individual reports. HY-8 .hy8/.rst adapter, explicit flow selection and barrel scope. Never assume all events share tailwater or velocity decay.
M6 GUI: Tkinter + Matplotlib embedded charts, optional Plotly offline HTML for orbitable 3D. Tabs inputs/import, batch, hydraulics, methods, alternatives, visuals, QC/inferences, export. Same result model feeds GUI and reports. Plan/profile/cross section, velocity-distance plot with thresholds, scour dimensions, stone classes, event envelope. 3D conceptual geometry only unless surveyed geometry provided; label interpolated surface as inference, no CFD claims. Orbit, pan, zoom, reset, equal units, export static views with scale and orientation. PDF via reportlab with figures and full ten-block calculation report; HTML interactive companion, CSV/JSON. No GUI-specific engineering formulas.
M7 validation: run legacy and new tests, published examples, real anonymized HY-8 exports, GUI smoke tests, batch failure tests, report consistency checks. Record environment and exact results. Release only after unresolved engineering blockers addressed.

M2 source checks include the FHWA HEC-14 errata dated 2012-10-01 and the archived HEC-11 reference in Step 5. Review HEC-23 for current riprap guidance. Applicability of specific replacement provisions is UNVERIFIED.
