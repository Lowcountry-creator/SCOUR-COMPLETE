The Option 2 probe checks the named class and thickness. The curve-fit probe is diagnostic.

## Engineering basis and limitations

FHWA HEC-14 (July 2006, third edition), Chapter 10, governs the new basin and apron checks. The exit calculation uses the supplied trapezoidal side slope. Regression tolerances accommodate the rounded quantities printed in the worked examples. The acceptance check uses unrounded velocity. Table 10.1 uses FHWA example classes. SCDOT reach classifications use the 2025 material table. Confirm the contract edition for each project.
